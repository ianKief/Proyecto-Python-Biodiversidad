# caracteristicas de los datasets
## IADIZA:
1. Nombre del dataset:

   GBIF Download Service. O como titulo alternativo "Colección Ornitológica del IADIZA-CCT CONICET Mendoza: IADIZA-COI".

2. Institución proveedora:

    IADIZA CCT CONICET Mendoza.

3. Cantidad de registros:

   2.365 registros contiene este dataset.

   > "2.365 registros que corresponden a la Colección Ornitológica del IADIZA CCT CONICET Mendoza (IADIZA-COI). La Colección incluye datos de aves. El Curador de esta colección es Paulo Emilio Llambias, Dr. Ciencias Naturales."
4. Cobertura geográfica:

   Los datos pertenecientes al dataset fueron tomados principalmente de argentina y paises limitrofes. Aqui las coordenadas:
   
     oeste: 71.647

     este: 53.735

     norte: 46.02

     sur: 22.25   

5. Cobertura temporal:

    publicado: 2017-10-04

    actualizado:2026-02-17

6. Separador de campos utilizado en los archivos :

   Los campos se separan con saltos de linea("/n"), y las lineas se separan con tabulador("/t")

7. Codificación de caracteres (encoding):

   UTF-8
